# Changelog

## Alpha 0.37.3

### Highlights

- Introduced the redesigned high-fidelity MXPulse settings interface
- Added clickable element enable/disable controls and a clickable F9 close button
- Reorganized settings pages and simplified the Widgets configuration flow
- Improved universal cursor alignment, hitbox behavior and automatic hiding
- Added fixed default positions so first-time users can access every widget immediately
- Improved Standings rider detection, player-row highlighting and session transitions
- Improved race position handling across qualifying and race sessions
- Added cleaner automatic resets between Practice, Qualifying, Warm-up and consecutive Race sessions
- Improved map rendering, markers, sector lines and finish-line visualization
- Added live Delta Bar functionality
- Improved visual consistency, font roles, shadows and scaling behavior
- Added English and Brazilian Portuguese localization
- Reduced unnecessary rendering work and improved performance on larger servers
- Updated the installer with automatic MX Bikes detection and preference-preserving updates
